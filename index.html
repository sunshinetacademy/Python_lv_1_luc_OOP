المستوى الأول 🟢 Class و Object

📐 المفاهيم الأساسية:

  • Class: القالب/التصميم (مثل مخطط البناء)
  • Object: نسخة من Class (مثل المبنى الفعلي)
  • Attributes: بيانات الكائن (مثل: الاسم، العمر)
  • Methods: أفعال الكائن (مثل: يمشي، يهاجم)

🐍 مثال 1: Class بسيط

class Dog: def __init__(self, name, age): self.name = name self.age = age def bark(self): print(f"{self.name} يقول: Woof! 🐕") # إنشاء Object dog1 = Dog("Rex", 3) dog1.bark() # Rex يقول: Woof! 🐕

💡 ملاحظات مهمة:

  • ✅ نستخدم class لتعريف Class
  • ✅ اسم Class يبدأ بحرف كبير (PascalCase)
  • ✅ __init__ تُنفذ تلقائياً عند إنشاء Object
  • ✅ self يشير للكائن نفسه

المستوى الثاني 🟡 __init__ و self

دالة __init__ (المنشئ)

تُنفذ تلقائياً عند إنشاء Object جديد. تستخدم لتهيئة البيانات!

class Student: def __init__(self, name, age, grade): self.name = name # Attribute self.age = age self.grade = grade print(f" تم إنشاء طالب: {name}") # إنشاء Objects s1 = Student("Ahmed", 15, "A") s2 = Student("Sara", 14, "B")

🎯 ما هو self؟

self يشير إلى الكائن الحالي. بدونه، Python لا تعرف أي Object نتحدث عنه!

🎮 جربها بنفسك
class Car: def __init__(self, brand, color, year): self.brand = brand self.color = color self.year = year print(f"🚗 تم إنشاء سيارة: {brand}") def honk(self): print(f"{self.brand} تقول: Beep! ") # إنشاء سيارات car1 = Car("BMW", "Black", 2020) car2 = Car("Toyota", "White", 2019) car1.honk() car2.honk()

class Player: def __init__(self, name, health, level): self.name = name self.health = health self.level = level def attack(self, enemy): print(f"⚔️ {self.name} يهاجم {enemy.name}!") enemy.health -= 10 def status(self): print(f"🎮 {self.name} | HP: {self.health}") # إنشاء لاعبين hero = Player("Ahmed", 100, 5) villain = Player("Dragon", 80, 7) hero.status() villain.status() print("\n--- المعركة ---") hero.attack(villain) villain.status()

🎯 Class Attributes (بيانات مشتركة)

class Game: players_count = 0 # Class Attribute (مشترك) def __init__(self, name): self.name = name # Instance Attribute (خاص) Game.players_count += 1 g1 = Game("Minecraft") g2 = Game("Fortnite") print(Game.players_count) # 2

🎮 جربها بنفسك - نظام أسلحة
class Weapon: def __init__(self, name, damage): self.name = name self.damage = damage class Player: def __init__(self, name): self.name = name self.weapon = None def equip(self, weapon): self.weapon = weapon print(f"️ {self.name} equipped {weapon.name}!") def attack(self): if self.weapon: print(f"💥 {self.name} attacks with {self.weapon.name} for {self.weapon.damage} damage!") else: print(f"😢 {self.name} has no weapon!") # إنشاء أسلحة sword = Weapon("Magic Sword", 50) bow = Weapon("Elven Bow", 35) # إنشاء لاعب hero = Player("Ahmed") hero.attack() # لا سلاح! hero.equip(sword) hero.attack() # هجوم بالسيف!

🎨 المشروع: نظام شخصيات لعبة RPG

هنعمل نظام كامل لشخصيات لعبة مع معارك وعلاج!

️ نظام RPG الكامل

🎮 جرب المشروع
# ═══════════════════════════════════════ # 🎮 نظام شخصيات لعبة RPG # ═══════════════════════════════════════ class Character: def __init__(self, name, health, attack_power, level): self.name = name self.health = health self.max_health = health self.attack_power = attack_power self.level = level self.xp = 0 def attack(self, enemy): damage = self.attack_power enemy.health -= damage print(f"⚔️ {self.name} يهاجم {enemy.name} بـ {damage} ضرر!") print(f" {enemy.name} HP: {enemy.health}/{enemy.max_health}") if enemy.health <= 0: print(f"💀 {enemy.name} هُزم!") self.xp += 50 print(f"✨ {self.name} gained 50 XP!") def heal(self): heal_amount = 30 self.health += heal_amount if self.health > self.max_health: self.health = self.max_health print(f"💊 {self.name} استعاد {heal_amount} HP!") print(f" {self.name} HP: {self.health}/{self.max_health}") def status(self): print(f"\n🎮 === {self.name} ===") print(f" ❤️ HP: {self.health}/{self.max_health}") print(f" ⚔️ Attack: {self.attack_power}") print(f" 🎯 Level: {self.level}") print(f" ✨ XP: {self.xp}") print(f"{'='*30}") # إنشاء شخصيات hero = Character("Ahmed", 100, 25, 5) villain = Character("Dragon", 80, 30, 7) print("🎮 مرحباً بك في لعبة RPG!") print("=" * 40) # عرض الحالة hero.status() villain.status() # المعركة print("\n⚔️ --- المعركة تبدأ! ---") hero.attack(villain) villain.attack(hero) # العلاج print("\n --- العلاج ---") hero.heal() # الحالة النهائية print("\n📊 --- الحالة النهائية ---") hero.status() villain.status()
